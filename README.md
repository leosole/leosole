### 📦 Selected Projects

#### **[timeline-tasks](https://github.com/leosole/timeline-tasks)** — published React library · [npm](https://www.npmjs.com/package/timeline-tasks) · [live demo](https://leosole.github.io/timeline-tasks/)

A React timeline component for project tasks: task bars with due dates, overdue and delay overlays, day/week/month zoom, collapsible grouping, filters, status colors and a task detail popover. `Timeline` renders the grid while a `useTimeline()` hook exposes state for consumer-built controls. ESM/CJS builds with type declarations, Vitest tests in CI and semantic-release publishing.

#### **[gsheets-timeline](https://github.com/leosole/gsheets-timeline)** — Google Sheets add-on and web app

Turns a spreadsheet into a configurable timeline, shipping a web app and a Sheets add-on from one React bundle. Read-only by design: it modifies no sheet data.

#### **[CheckUpTrack](https://github.com/leosole/checkup-track)** — personal health-records dashboard

Parses lab-report PDFs into structured biomarker data behind an API-first FastAPI backend with stateless JWT auth, and visualizes trends, exams, medications and a combined calendar in React.

#### **LLM-powered CV chat** — [leosole-cv.netlify.app](https://leosole-cv.netlify.app/)

Production LLM feature using JSON-schema prompt templates, streaming with error boundaries, conversation context management and MongoDB persistence.
